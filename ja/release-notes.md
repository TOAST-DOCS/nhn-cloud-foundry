### 2026. 09. XX. { #foundry.release.notes.2026.09.xx }

<a id="foundry.release.notes.2026.09.xx.feature"></a>
#### 新規機能追加 { #foundry.release.notes.2026.09.xx.feature }

- アプリに**単変量異常検出**タイプを追加しました。収集したメトリクスを時系列ごとに学習して異常スコアと基準値を計算し、指定した Prometheus に転送すると同時に結果データソースに保存します。
- メトリクス（時系列）データをリアルタイムで受信する **Prometheus API** タイプのデータソースを追加しました。データソースの詳細画面にある**[収集方法]**タブで転送方法を確認できます。
- データソースの詳細画面に**[イベント設定]**タブを追加しました。Event API を有効にすると、既存のデータを維持したまま変更イベントを API で収集できます。
- 推薦システムアプリの詳細画面に**[学習管理]**タブを追加しました。学習周期の変更、自動再学習の停止・再開、学習の手動実行、学習成果物の履歴照会が行えます。
- アプリ作成画面に**[リソース確認]**を追加しました。アプリを作成する前に、作成可能かどうかを確認できます。
- 推薦照会 API の `context` に行動シグナル（`impressions`、`interactions`、`feedback`）を追加しました。渡したシグナルは推薦結果の順序を調整するために使用されます。

<a id="foundry.release.notes.2026.09.xx.improvement"></a>
#### 機能改善/変更 { #foundry.release.notes.2026.09.xx.improvement }

- チャートの照会に失敗した場合、クエリエンジンが返したエラー内容を画面に表示するよう改善しました。
- チャート一覧のデータソース列を ID の代わりに名前で表示します。
- チャート編集画面でデータソースの設定をロック状態で表示します。
- コンソールに表示される日付と時刻を、アクセスしたブラウザのタイムゾーン基準に統一しました。
- 指標収集 API のリクエスト制約（項目数の上限、必須フィールド、ラベルルール）とエラーレスポンスを整備しました。

<a id="foundry.release.notes.2026.08.25"></a>
### 2026. 08. 25. { #foundry.release.notes.2026.08.25 }

<a id="foundry.release.notes.2026.08.25.new.service"></a>
#### 新規サービスリリース { #foundry.release.notes.2026.08.25.new.service }

- NHN Cloud Foundry がリリースされました。
- 次の機能を使用できます。
    - データソース: スキーマを定義してデータソースを作成し、ファイルアップロードまたは Ingest API (スナップショットアップロード) でデータを取り込んで、レコメンデーション・分析に使用できます。
    - 分析: 取り込んだデータをクエリで照会し、チャート・ダッシュボードで可視化して分析できます。
    - パイプライン: データソースのデータをフィルタリング・集計・結合などで加工して分析可能なデータセットに変換し、バッチスケジュールに基づく自動実行をサポートします。変換したデータセットは分析やレコメンデーションモデルの学習に使用できます。
    - アプリ: ユーザー・アイテム・インタラクションデータでレコメンデーションモデルを学習したレコメンデーションシステムアプリを作成し、レコメンデーション API でレコメンデーション結果をサービスに活用できます。
