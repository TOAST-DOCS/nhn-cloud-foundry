<a id="foundry.overview"></a>
## Machine Learning > NHN Cloud Foundry > 概要 { #foundry.overview }

NHN Cloud Foundry は、お客様のデータを統合し、機械学習モデル（レコメンデーション、時系列予測/異常検知、構造化データ分類/数値予測など）を活用して効果的な意思決定を支援するサービスです。
データを取り込み、ビジュアルワークフローで加工した後、クエリ/チャート/ダッシュボードで分析したり、レコメンデーションモデルを連携したアプリを作成してレコメンデーション結果をサービスに活用できます。

<a id="main.feature"></a>
## 主要機能 { #main.feature }

| 機能 | 説明 |
| --- | --- |
| **データソース** | 分析するデータを保存する単位。スキーマを定義してデータソースを作成しデータを積載します。作成済みのデータソースは Ingest API でデータの追加・更新が可能です。メトリクス（時系列）データをリアルタイムで受け取るデータソースも作成できます。 |
| **パイプライン** | データソースのデータをノードを接続したワークフローで加工し、分析やモデル学習に使用するデータセットに変換します。バッチスケジュールによる自動実行をサポートします。 |
| **分析** | データを SQL **クエリ**で照会し、**チャート**で可視化し、**ダッシュボード**で統合モニタリングします。 |
| **アプリ** | AIモデルをデータに接続してアプリを作成、管理します。推薦システムと単変量異常検出の2つのタイプを提供します |

<a id="datasource"></a>
## データソース { #datasource }

データソースは、NHN Cloud Foundry で分析するデータを格納する単位です。
スキーマを定義してデータソースを作成すると、データがテーブルに格納され、その後パイプライン/分析/アプリでこのデータを使用します。

データソースはコンソールで作成し、作成時にデータを一緒にアップロードできます。
作成済みのデータソースにデータを追加または更新する場合は、Ingest API を使用します。
データ全体を置き換えるスナップショットアップロードと、既存のデータを保持したまま新しいデータを追加するイベント方式を提供します。

指標データを扱う際は、Prometheus API タイプのデータソースを作成し、収集 API でリアルタイム転送します。このように積載した指標は、単変量異常検出アプリの入力として使用します。

!!! danger "注意"
    本サービスをご利用の際は、個人情報を含む情報を入力しないようにご注意ください。
    本サービスは、お客様が入力する個人情報に対する個別のセキュリティ確保措置を提供していないため、個人情報を含む情報の入力および保存はお控えください。

<a id="pipeline"></a>
## パイプライン { #pipeline }

データソースのデータをノードを接続したビジュアルワークフローで加工し、分析可能なデータセットに変換する機能です。
変換されたデータセットはデータソースとして登録され、分析やアプリのレコメンデーションモデルの学習データとして使用できます。

- ソースデータの接続とスキーマの自動検出
- 行フィルタリング、カラム加工、集計、結合、ユニオンなどの変換処理
- バッチスケジュール設定による自動実行
- コンピューティングリソースの設定と実行履歴の管理

<a id="analysis"></a>
## 分析 { #analysis }

データソースに格納されたデータを照会/可視化/モニタリングします。
クエリでデータを確認し、チャートを作成してダッシュボードに配置する順序で使用します。

| 機能 | 説明 |
| --- | --- |
| クエリ | SQL を使用したデータソースのデータ照会と実行履歴の管理 |
| チャート | 照会したデータの可視化 |
| ダッシュボード | 複数のチャートを一画面に配置して統合モニタリング |

<a id="app"></a>
## アプリ { #app }

AI モデルをデータに接続してアプリを作成・管理する機能です。アプリのタイプは、推薦システムと単変量異常検出の2種類を提供します。

**推薦システム**は、使用する推薦モデルを選択し、ユーザー/アイテム/ヒストリーのデータソースを接続すると、学習とデプロイが自動的に進行します。アプリがアクティブ状態になると、推薦 API を要請できます。
推薦結果はコンソールから直接呼び出して確認するか、API で要請できます。ユーザーの反応を推薦イベント API で収集すると、積載されたイベントデータから推薦の成功率を分析できます。
学習周期の変更、自動再学習の停止・再開、学習の直接実行、学習成果物の実行履歴の照会もコンソールから行えます。

**単変量異常検出**は、収集したメトリクスを時系列ごとに学習し、正常範囲を外れた値を検出します。
検出結果である異常スコアと基準値は、指定した Prometheus に転送され、同時に結果データソースにも保存されて分析に使用できます。

<a id="public.api"></a>
## API { #public.api }

NHN Cloud Foundry は、コンソールに加えて API も提供します。
作成済みのデータソースにスナップショット・イベント・メトリクスを積載する Ingest API と、作成したアプリの推薦結果を要請し、ユーザーの反応イベントを転送する API を使用できます。

詳細については、[API ガイド](../api-guide/)を参照してください。

<a id="target"></a>
## サービス対象 { #target }

- データインフラを自分で構築せずに、データの積載・加工・分析環境が必要なチーム
- 散在するデータを一か所に集めて定期的に加工し、メトリクスとして確認したいサービス
- 別途のモデル学習・サービング環境なしに推薦結果をサービスに適用したいチーム
- 収集中のメトリクスから異常兆候を自動的に検出したいチーム
