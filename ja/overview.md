<a id="foundry.overview"></a>
## Machine Learning > NHN Cloud Foundry > 概要 { #foundry.overview }

NHN Cloud Foundry は、お客様のデータを統合し、機械学習モデル（レコメンデーション、時系列予測/異常検知、構造化データ分類/数値予測など）を活用して効果的な意思決定を支援するサービスです。
データを取り込み、ビジュアルワークフローで加工した後、クエリ/チャート/ダッシュボードで分析したり、レコメンデーションモデルを連携したアプリを作成してレコメンデーション結果をサービスに活用できます。

!!! danger "注意"
    本サービスを利用する際は、個人情報を含む情報を入力しないでください。
    本サービスは、お客様が入力する個人情報に対する別途の安全性確保措置を提供していないため、個人情報を含む情報の入力および保存は行わないでください。

<a id="main.feature"></a>
## 主要機能 { #main.feature }

| 機能 | 説明 |
| --- | --- |
| **データソース** | 分析するデータを格納する単位です。スキーマを定義してデータソースを作成し、データを取り込みます。作成済みのデータソースは Ingest API でデータの追加/更新が可能です。 |
| **パイプライン** | データソースのデータをノードを接続したワークフローで加工し、分析やモデル学習に使用するデータセットに変換します。バッチスケジュールによる自動実行をサポートします。 |
| **分析** | データを SQL **クエリ**で照会し、**チャート**で可視化し、**ダッシュボード**で統合モニタリングします。 |
| **アプリ** | レコメンデーションモデルをデータに連携してレコメンデーションシステムアプリを作成/管理します。レコメンデーション結果はコンソールと API で確認できます。 |

<a id="datasource"></a>
## データソース { #datasource }

データソースは、NHN Cloud Foundry で分析するデータを格納する単位です。
スキーマを定義してデータソースを作成すると、データがテーブルに格納され、その後パイプライン/分析/アプリでこのデータを使用します。

データソースはコンソールで作成し、作成時にデータを一緒にアップロードできます。
作成済みのデータソースにデータを追加または更新する場合は、Ingest API を使用します。
データ全体を置き換えるスナップショットアップロードと、既存のデータを保持したまま新しいデータを追加するイベント方式を提供します。

<a id="pipeline"></a>
## パイプライン { #pipeline }

データソースのデータをノードを接続したビジュアルワークフローで加工し、分析可能なデータセットに変換する機能です。
変換されたデータセットはデータソースとして登録され、分析やアプリのレコメンデーションモデルの学習データとして使用できます。

- ソースデータの接続とスキーマの自動検出
- 行フィルタリング、カラム加工、集計、結合、ユニオンなどの変換処理
- バッチスケジュール設定による自動実行
- コンピューティングリソースの設定と実行履歴の管理

<a id="analysis"></a>
## 分析 { #analysis }

データソースに格納されたデータを照会/可視化/モニタリングします。
クエリでデータを確認し、チャートを作成してダッシュボードに配置する順序で使用します。

| 機能 | 説明 |
| --- | --- |
| クエリ | SQL を使用したデータソースのデータ照会と実行履歴の管理 |
| チャート | 照会したデータの可視化 |
| ダッシュボード | 複数のチャートを一画面に配置して統合モニタリング |

<a id="app"></a>
## アプリ { #app }

レコメンデーションモデルをデータに連携してレコメンデーションシステムアプリを作成・管理する機能です。
使用するレコメンデーションモデルを選択し、ユーザー/アイテム/ヒストリーデータソースを接続すると、学習とデプロイが自動的に進行します。アプリがアクティブ状態になると、レコメンデーション結果を活用できます。

レコメンデーション結果はコンソールから直接呼び出して確認するか、API でリクエストできます。ユーザーの反応をレコメンデーションイベント API で収集すると、蓄積されたイベントデータでレコメンデーション成功率を分析できます。

<a id="public.api"></a>
## API { #public.api }

NHN Cloud Foundry はコンソールに加えて、API も提供します。
作成済みのデータソースにデータを追加・更新する Ingest API と、作成したアプリのレコメンデーション結果をリクエストしてユーザー反応イベントを送信する API を使用できます。

詳細については、[API ガイド](../api-guide/)を参照してください。

<a id="target"></a>
## サービス対象 { #target }

- データインフラを自社で構築せずに、データの取り込み/加工/分析環境が必要なチーム
- 分散したデータを一か所に集めて定期的に加工し、指標として確認したいサービス
- 独自のモデル学習・サービング環境なしにレコメンデーション結果をサービスに適用したいチーム
